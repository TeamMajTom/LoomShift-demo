# LoomShift-demo

**Sprintboard** — a small single-page task board (To do / Doing / Done) for a solo founder.

This is currently the scaffolded app shell only. The board itself is a follow-up change.

## Stack

React + TypeScript, built with Vite. ESLint for linting, Vitest + React Testing Library for tests.

## Scripts

```
npm install
npm run dev        # start the dev server
npm run typecheck  # tsc project build, no emit
npm run lint       # eslint
npm run test       # vitest
npm run build      # production build
```
